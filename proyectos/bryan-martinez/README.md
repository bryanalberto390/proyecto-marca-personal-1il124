📚 UTP Academic Core - Sistema de Registro Estudiantil

Aplicación en consola desarrollada en Java para la gestión y administración de datos académicos de estudiantes universitarios. 

🚀 Características
- Programación Orientada a Objetos (POO):Encapsulamiento, separación de responsabilidades y modularidad.
- Persistencia de Datos:Guardado y lectura automática en archivo plano `estudiantes.txt` (CSV format).
- Manejo de Colecciones:Uso de `ArrayList` para almacenamiento dinámico en memoria.
- Control de Excepciones: Validación de entradas por consola para evitar errores de ejecución.

 🛠️ Tecnologías e Herramientas
- Lenguaje:Java 17 / JDK 21
- IDE Recomendado:Visual Studio Code / Eclipse / IntelliJ IDEA
- Control de Versiones:Git / GitHub
