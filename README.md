Sistemas Colaborativos — UTP




Descripción del proyecto

Este proyecto universitario tiene como objetivo desarrollar y presentar la marca personal profesional de los integrantes del grupo, orientada al área de Ingeniería de Sistemas Computacionales.

Mediante el uso de GitHub y herramientas digitales colaborativas, se busca organizar un portafolio profesional que permita mostrar habilidades técnicas, proyectos académicos, conocimientos adquiridos y documentación de los trabajos realizados.

El repositorio funciona como un espacio compartido para documentar avances, organizar recursos y fortalecer la presencia profesional de cada integrante en el ámbito tecnológico.

Desarrollar una identidad profesional orientada al área de tecnología.

Crear y mantener un portafolio digital de proyectos académicos.

Aplicar buenas prácticas de documentación mediante archivos Markdown.

Utilizar Git y GitHub para el control de versiones y la colaboración.

Presentar las habilidades y los proyectos de los integrantes de manera organizada.
